# Fotografies editorials — 23 setembre 2026

Selecció de 30 fotografies originals del disc ADATA SD700: 20 portades i 10 imatges dins dels articles. Cada original té una assignació única, documentada a [sources.json](sources.json), i tres versions WebP de 4:3: 1440 × 1080, 960 × 720 i 640 × 480 píxels.

El [mosaic de revisió](contact-sheet.jpg) mostra els retalls finals de 1440 píxels, identificats per ID de font i article. Les fotografies verticals s'han enquadrat manualment per conservar la cara o l'acció clínica principal. La portada de sagnat de genives (font 227) mostra l'atenció a una pacient; la font 138 s'utilitza com a primer pla de la higienista a l'article sobre el mal alè.

Les fonts JPEG tenien perfil Adobe RGB (1998); la font HEIC 16 tenia Display P3. Totes s'han convertit a sRGB abans de l'exportació. Els WebP no contenen EXIF, XMP ni perfil ICC incrustat.

**Exclusió permanent:** la fotografia del noi somrient `DENTAL CARRERA/FOTOS/CLINICA/DSCF0487.jpg` (font 124) i qualsevol derivat no s'han d'utilitzar ni publicar. També hem exclòs per prudència `DENTAL CARRERA/FOTOS/CLINICA/DSCF0379.jpg` (font 118), una altra fotografia similar. Els SHA-256 d'ambdues fonts consten a [sources.json](sources.json) perquè es puguin identificar encara que canviï el nom del fitxer. Cap d'aquestes dues fotografies no forma part dels WebP generats.

La validació local ha comprovat 30 fonts úniques, 90 fitxers WebP, les dimensions de cada variant i l'absència de metadades. Aquesta carpeta no acredita publicació ni desplegament.
