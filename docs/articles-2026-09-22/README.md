# Articles de setembre: ampliació del 22/09/2026

Publicació conjunta de 14 temes en català i castellà autoritzada pel responsable del web. S’exclou la proposta sobre preus d’implants. Les oportunitats editorials provenen de la revisió de Brånemark, Clínica Chela, Ilerdent, Meridian i altres clíniques de Lleida; això no acredita trànsit ni demanda quantificada.

Els textos són originals i contrastats amb fonts sanitàries enllaçades a cada article. No s’atribueix autoria ni revisió clínica als professionals de Carrera. La revisió de fonts no equival a una revisió clínica individual per part de la clínica. Les notes de fonts dels tres mòduls detallen els límits de les afirmacions.

## Verificació i indexació

La publicació es comprova amb build, proves existents, revisió del render i comprovacions HTTP de les URLs públiques. L’enviament a Search Console s’ha de fer amb el sitemap de producció actualitzat. Un enviament acceptat o una prova en directe correcta no demostren indexació: Google decideix la incorporació i el termini.

### Validació local

- Build final correcte i 158 proves existents superades.
- 94 URLs del sitemap amb HTTP 200, un H1, idioma correcte, canonical propi, hreflang recíproc i sense meta noindex; 70 guies i 35 targetes a cada blog. La previsualització local conserva expressament una capçalera noindex.
- Revisió al navegador de l’article de tria de dentista i del blog ES, en escriptori i a 390 × 844: títols, text, fotografia, peu fix de contacte, graella i filtre «La visita dental» (2 articles) correctes. Vista del navegador restaurada.
- 67 fonts externes comprovades per HTTP: 59 respostes 200, una 202 i set 403 de proteccions contra automatització. Cap resposta 404. La lectura i el contrast de les fonts estan documentats a les notes editorials; un 403 del comprovador no s’interpreta com a article desaparegut.
