# Fonts i límits editorials: consulta i símptomes

Data de comprovació: 22 de setembre de 2026.

Mòdul: `data/guides-access-symptoms.js` (5 temes, 10 pàgines CA/ES).

Text original per a pacients. Els exemples de conversa, els criteris per preparar una visita i les preguntes són elaboració editorial; les afirmacions sanitàries es basen en fonts professionals i públiques. No s’ha utilitzat contingut de clíniques competidores com a font clínica ni s’ha atribuït una revisió fictícia a cap odontòleg.

| [ADA: anestèsia i sedació](https://www.mouthhealthy.org/all-topics-a-z/anesthesia-and-sedation) | Diferència de finalitat entre anestèsia local i sedació; elecció segons antecedents, procediment i valoració. |

## Sensibilitat dental amb el fred

Slugs: `sensibilitat-dental-fred`, `sensibilidad-dental-frio`.

| Font comprovada | Ús delimitat |
| --- | --- |
| [ADA: sensitive teeth](https://www.mouthhealthy.org/all-topics-a-z/sensitive-teeth) | Dentina i cobertura protectora; retracció, desgast, restauracions i altres causes. Pasta desensibilitzant com a opció segons causa, amb efecte no necessàriament immediat. |
| [AAE: tooth pain](https://www.aae.org/patients/dental-symptoms/tooth-pain/) | Importància de la durada, estímuls i dolor en mossegar; indicació d’avançar la valoració si persisteix o empitjora. |
| [NIDCR: tooth decay](https://www.nidcr.nih.gov/health-info/tooth-decay) | Càries inicial sovint sense símptomes; sensibilitat i dolor possibles quan avança. |
| [NHS: higiene dental](https://www.nhs.uk/live-well/healthy-teeth-and-gums/how-to-keep-your-teeth-clean/) | Mantenir raspallat amb pasta fluorada i neteja adequada. |
| [NHS: bruxisme](https://www.nhs.uk/symptoms/teeth-grinding/) | Desgast o fractures relacionats amb bruxisme poden contribuir a sensibilitat; no s’infereix necessitat de fèrula a partir del fred. |

Límits: no s’utilitza un llindar de segons per diagnosticar pulpitis ni un termini universal d’espera després d’un tractament. El dolor persistent, espontani, nocturn o en mastegar demana valoració. Sense equivalència automàtica entre sensibilitat i càries/endodòncia.

## Bony a la geniva i possible fístula

Slugs: `bony-geniva`, `bulto-encia`.

| Font comprovada | Ús delimitat |
| --- | --- |
| [NHS: dental abscess](https://www.nhs.uk/conditions/dental-abscess/) | Símptomes d’infecció, necessitat d’atenció urgent i escalada immediata davant afectació respiratòria/deglutòria, ocular o limitació important d’obertura. |
| [AAE: abscessed teeth](https://www.aae.org/patients/dental-symptoms/abscessed-teeth/) | La infecció pot no ser dolorosa; tractament dirigit a l’origen i valoració de conservació. |
| [AAE: Colleagues for Excellence, 2019/2021](https://www.aae.org/specialty/wp-content/uploads/sites/2/2019/12/ecfe-fall-2019-May-2021.pdf) | Abscés apical crònic amb trajecte de drenatge i símptomes lleus; no confondre drenatge amb curació. |
| [AAE: lesions endoperiodontals](https://www.aae.org/specialty/endodontic-periodontic-lesions/) | Història, proves dentals i periodontals per diferenciar presentacions semblants. |
| [NHS: símptomes orals persistents](https://www.nhs.uk/conditions/mouth-cancer/symptoms/) | Un bony o una lesió persistent necessita exploració; el símptoma no equival a un diagnòstic greu. No s’utilitza la font per insinuar que el bony sigui càncer. |
| [ADA: antibiòtics i dolor/inflor dental](https://www.ada.org/resources/research/science/evidence-based-dental-research/antibiotics-for-dental-pain-and-swelling/) | Antibiòtic no automàtic; decisió segons clínica i situació de salut, amb tractament de la causa. |
| [Generalitat: 112](https://112.gencat.cat/ca/inici) | Adaptació del canal d’emergències al context català, sense reproduir els números britànics NHS. |

Límits: «bony» no es diagnostica automàticament com abscés/fístula. No es dona un termini per esperar una lesió nova ni s’aconsella observar-la tres setmanes abans de consultar. Les dues llengües indiquen 112 en emergències, i no esperar resposta del formulari. Sense cobertura 24 h atribuïda a Carrera. Sense antibiòtics, drenatge casolà o extracció automàtica.
